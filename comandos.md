# Comandos

## Gerar uma página a partir de um print

Anexe o print da tela e envie o prompt abaixo, trocando `NOME` pelo nome da página (ex.: `perfil`).

```
Faça a página do print anexado no arquivo public/pages/NOME.html, só com HTML e CSS e se tiver funcionalidades adicione um JS.
Siga o padrão das páginas que já existem:
- use a mesma navbar e o mesmo rodapé das outras páginas;
- use as variáveis e classes do assets/css/style.css e coloque o CSS próprio da página em assets/css/NOME.css;
- use ícones do Lucide (assets/js/lucide.min.js);
- dados fixos (mock), sem comentários no código e responsivo para celular.
```
