## Descrição

Reprodução do site Climatempo, feita para a disciplina de Desenvolvimento Web I com HTML, CSS e JavaScript.

Páginas:

- `index.html`: página inicial, com busca de cidade
- `pages/principal.html`: previsão do tempo
- `pages/preview.html`: prévia da previsão
- `pages/planos.html`: planos de assinatura
- `pages/login.html`: login
- `pages/cadastro.html`: cadastro
- `pages/perfil.html`: perfil do usuário

## Como usar

1. Clone o repositório:
   ```bash
   git clone <url-do-repositorio>
   ```
2. Abra o arquivo `docs/index.html` no navegador.
